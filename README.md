# About the project

**Midwest Family Building Resource is a portfolio project exploring what a future nonprofit could look like. It is designed to provide neutral, non-religious, apolitical, evidence-based information about all paths to parenthood; including IVF, adoption, fostering, surrogacy, and traditional childbirth, along with the concept of a micro-grant program to support families.**

Live Demo:
https://midwest-family-building-resource.vercel.app/

---

While this is not currently an active nonprofit or fundraising organization, it represents a real-world concept that may be developed further in the future.

The site demonstrates:

- Honest cost guides for every family-building path
- State-specific resource directories for Missouri and Illinois residents
- A conceptual direct-to-provider micro-grant model
- Evidence-based blog content covering medical, legal, and financial topics

## Tech stack

This is a Next.js 15 application built with the App Router pattern.

- **Framework:** Next.js 15 (React 19)
- **Language:** TypeScript
- **Styling:** CSS Modules (with shared design tokens)
- **Hosting:** Vercel
- **Future integrations:** Supabase (database), Stripe (donations - tests only)

## Project status

🚧 **In development as a portfolio piece.** This project is being built to showcase frontend development, UX thinking, and real-world problem framing.

It is not currently operating as a nonprofit, accepting donations, or distributing grants. However, it is intentionally designed with the potential to evolve into a real nonprofit initiative in the future.
