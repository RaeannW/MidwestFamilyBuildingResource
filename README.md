# Midwest Family Building Resource

**Free, evidence-based resources and direct micro-grants for families navigating every path to parenthood. Built for Missouri and Illinois.**

[midwestfamilybuildingresource.org](https://midwestfamilybuildingresource.org) _(coming soon)_

## About the project

Midwest Family Building Resource is a nonprofit initiative providing neutral, non-religious, apolitical, evidence-based information about all paths to parenthood; including IVF, adoption, fostering, surrogacy, and traditional childbirth. The nonprofit also holds a quarterly micro-grant program to help families afford fertility treatment.

The site offers:

- Honest cost guides for every family-building path
- State-specific resource directories for Missouri and Illinois residents
- Direct-to-provider micro-grants funded through community donations
- Evidence-based blog content covering medical, legal, and financial topics

All resources are free, always, with no sponsors or ads.

## Mission

Every family deserves a clear path forward. We believe:

- **Information should be free.** Nobody should hit a paywall while researching how to grow their family.
- **Information should be neutral.** No path to parenthood is inherently better than another.
- **Information should be honest.** Real costs, real timelines, real challenges; not sanitized marketing.
- **Support should reach providers directly.** Grant funds go straight to licensed family-building service providers, never as cash.

## Values

We are committed to being:

- **Neutral** — Evidence-based information without preferences, preaching, or agenda
- **Inclusive** — Welcoming all family structures regardless of marital status, sexual orientation, gender identity, religion, or race
- **Direct** — Clear information, real costs, no jargon, no sugarcoating

## Tech stack

This is a Next.js 15 application built with the App Router pattern.

- **Framework:** Next.js 15 (React 19)
- **Language:** TypeScript
- **Styling:** CSS Modules (with shared design tokens)
- **Hosting:** Vercel
- **Future integrations:** Supabase (database), Stripe (donations)
